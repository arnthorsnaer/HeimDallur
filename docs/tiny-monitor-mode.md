# Tiny Monitor Mode

Tiny Monitor Mode is a compact TUI designed for **66×20 terminal cells**, matching an
800×480 display (e.g. HyperPixel 4") running a Linux console.

Launch it with:

```bash
python -m heimdallur --mode tiny
```

## Panels

Three panels cycle automatically every 10 seconds. When a fault is active the
display locks to STATUS and navigation is disabled until the fault clears.

| Panel | Key | Content |
|---|---|---|
| **STATUS** | (default) | Overall health summary, active faults, per-group device counts |
| **INTERNET** | `→` / `l` | WAN quality, IP/DNS/HTTP check results, speed test |
| **HOME** | `→→` / `ll` | Router stats, per-gateway latency and online device counts |

## Key bindings

| Key | Action |
|---|---|
| `→` / `l` / `Space` | Next panel |
| `←` / `h` | Previous panel |
| `q` | Quit |

## Status indicators

| Symbol | Meaning |
|---|---|
| `●` green | Healthy |
| `~` yellow | Degraded / partial loss |
| `✗` red | Unreachable / offline |
| `○` grey | Unknown (gateway suppressed) |

## Pi setup

On the Raspberry Pi with a HyperPixel 4" display, configure autologin and launch
`--mode tiny` from `.bash_profile`:

```bash
# /home/pi/.bash_profile
if [ "$(tty)" = '/dev/tty1' ]; then
    exec /home/pi/.local/bin/uv run --directory /opt/heimdallur \
         python -m heimdallur --mode tiny
fi
```

For the console to fill the 800×480 panel at 66×20 cells, set a 12×24 font:

```bash
sudo dpkg-reconfigure console-setup
# Encoding: UTF-8 → Guess optimal → Terminus → 12×24
```

Or set it directly in `/etc/default/console-setup`:

```
FONTFACE="Terminus"
FONTSIZE="12x24"
```

Then apply: `sudo setupcon`

## Screenshots

Screenshots for all scenarios are generated by `scripts/capture_all.py` and
saved to `docs/screenshots/tiny/`. Run them locally with:

```bash
python scripts/capture_all.py --output-dir docs/screenshots
```
